# Hackathon Demo Flow

1. Login.
2. Show dashboard.
3. Show different CPSE material descriptions.
4. Upload NTPC/ONGC CSV.
5. Show validation and cleaned descriptions.
6. Run AI matching.
7. Compare:
   - semantic score
   - attribute score
   - fuzzy score
   - explanation
8. Reviewer approves a near duplicate.
9. Platform generates National Material Code.
10. Show legacy CPSE codes mapped to one national material.
11. Open availability.
12. Show stock across CPSEs.
13. Create Material Request.
14. Preview highest-available-first allocation.
15. Submit and approve request.
16. Show inventory reservation/fulfilment.
17. Trigger mock SAP sync.
18. Show audit trail.
19. Export national registry.
