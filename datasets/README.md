# Demo datasets

Purposefully inconsistent CPSE descriptions are included to demonstrate harmonization.

Examples:

- `HEX BOLT M16X50 SS304`
- `BOLT HEXAGONAL M16 X 50 STAINLESS STEEL 304`
- `SS 304 HEX HEAD BOLT M16 X 50`

These should converge toward the same/near-duplicate national material after AI review.

`HEX BOLT M16X50 MS` has the same geometry but a different material grade.
It should require engineering review rather than automatic mapping.
